Basic greedy Chaitin-style graph coloring.

Repeatedly removes vertices with degree < numRegisters from a working copy of the graph, pushing them onto a stack. If all remaining vertices have degree ≥ numRegisters a spill candidate is chosen (web with highest degree) and marked as spilled (webToRegister = -1). The stack is then popped and each vertex is greedily assigned the lowest-numbered color not used by its already-colored neighbors.

Parameters
graphThe interference graph (web IDs as vertex info).
websOrdered list of webs.
numRegistersNumber of available physical registers (K).
Returns
AllocationResult with the register assignment. \par Complexity:
O(W * (W^2 + E)) where W is the number of webs and E is the number of directed adjacency entries in the current Graph<int>. The extra W factor comes from repeated simplify passes and the course graph's O(W) findVertex lookup.

Graph coloring with selective web spilling.

When basic coloring fails, iteratively selects up to maxSpills webs to commit to memory (spill) and retries coloring on the reduced graph. The spill-candidate selection heuristic should minimize the total number of spills while maximizing the chance of a successful coloring (e.g., prefer high-degree webs).

Parameters
graphThe interference graph.
websOrdered list of webs.
numRegistersNumber of available physical registers (K).
maxSpillsMaximum number of webs that may be spilled.
Returns
AllocationResult (spilled webs have webToRegister = -1). \par Complexity:
O((maxSpills + 1) * W * (W^2 + E)) with the implemented high-degree spill heuristic and vector-backed Graph<int>.

Graph coloring with selective web splitting.

When basic coloring fails, iteratively splits up to maxSplits webs into two derived sub-webs, reducing interference edges and hopefully allowing a coloring with the same number of registers. The split-point selection heuristic has a strong influence on the result.

After splitting, the web list and interference graph must be rebuilt before reattempting coloring.

Parameters
graphThe original interference graph.
websOrdered list of webs (may be extended with derived webs).
numRegistersNumber of available physical registers (K).
maxSplitsMaximum number of webs that may be split.
Returns
AllocationResult for the (possibly extended) web list. \par Complexity:
O((maxSplits + 1) * (W^2 * P + E * W + W * (W^2 + E))) in the worst case, where P is the maximum number of points compared per web pair. Each split rebuilds the interference graph and reruns coloring.

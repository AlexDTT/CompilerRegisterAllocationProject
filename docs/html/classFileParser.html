Detailed Description

Utility class with static methods to parse the two input files required by the compiler register allocation tool.

Two distinct file formats are handled:

  • Ranges file: maps variable names to their live ranges.
  • Config file: specifies the number of registers and the algorithm to use.

bool FileParser::parseRanges ( const std::string & filename,
std::map< std::string, std::vector< LiveRange > > & ranges )
static

Parses the live-ranges input file.

Expected format (one live range per line):

# comment
varname: 7+, 8, 9, 10-
varname: 15+, 16, 17-
other: 3+, 4-

A '+' suffix on a line number marks the start (definition); '-' marks the end (last use). Ranges without '+'/'-' on their endpoints are allowed (intersection-only ranges). Validation rule: for each variable, at least one '+' and at least one '-' must appear across all ranges of that variable.

Parameters
filenamePath to the ranges text file.
[out]rangesMap from variable name to the list of its parsed live ranges.
Returns
true on success, false if the file could not be opened or contains fatal errors. \par Complexity:
O(L * P) where L is the number of lines and P the average number of program points per line.

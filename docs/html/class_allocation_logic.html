Computes the maximum clique size (lower bound on chromatic number) of the interference graph using a greedy heuristic.

This gives a quick lower bound on the minimum number of registers required.

Parameters

Returns
Estimated lower bound on the chromatic number. \par Complexity:
O(W^3 + W * E) in the worst case with the current vector-backed Graph<int>, where W is the number of webs and E is the number of directed adjacency entries.

Exports a colored DOT graph for a completed allocation result.

Nodes are colored by assigned register. Memory-assigned webs use a neutral gray fill, and split-derived webs receive a highlighted border. The graph is written after the selected allocation algorithm has completed, so splitting mode exports the rebuilt graph with the final derived webs.

Parameters
graphFinal interference graph.
websFinal web list.
resultAllocation result to visualize.
filenameDestination DOT file path.
Returns
true on success, false if the file could not be created. \par Complexity:
O(W + E + S), where W is the number of webs, E is the number of directed adjacency entries, and S is the number of split records.

Runs the register allocation specified by params.

Dispatches to the appropriate GraphColoring method based on params.algorithm, then writes the result to params.outputFile via OutputWriter.

Parameters

paramsConfiguration (registers, algorithm, output file).
Returns
AllocationResult from the chosen algorithm. \par Complexity:
O(A + O_alg), where O_alg is the selected allocator's documented complexity and A is the number of output assignment/metadata records.
